Installing

Elenchus isn’t signed with paid Apple or Microsoft developer certificates yet, so your computer asks you to confirm the first time you open it. It’s one extra click. Only download Elenchus from this page.

Mac

  1. Open the downloaded .zip to unpack Elenchus.
  2. Drag Elenchus into your Applications folder.
  3. The first time only: right-click (or Control-click) Elenchus and choose Open, then Open again.
  4. If macOS says Elenchus “is damaged” or “can’t be opened”, go to System Settings › Privacy & Security and choose Open Anyway. If that option doesn’t appear, run this once in Terminal:
xattr -cr /Applications/Elenchus.app

Windows

  1. Run Elenchus-Windows-Setup.exe.
  2. If Windows SmartScreen appears, choose More info, then Run anyway.
  3. Accept the License Agreement and choose where to install. Elenchus adds a Start menu and desktop shortcut.
  4. To uninstall, use Settings › Apps. Your cases in Documents › Elenchus are kept.
Updating? Download and install the new version over the old one. Your cases and settings stay where they are.

What’s new in 4.0.2

  • On Mac, Elenchus no longer asks for your password or Keychain access.
  • The theory test uses the whole window on smaller and scaled screens, including Windows laptops.
  • Tighter security: the app can only reach the parts of your computer it needs and never loads content from the internet inside a case.
  • Fixes a problem in 4.0.0 that left the window blank on Mac and Windows.
  • Elenchus Pro is now $15 a month or $120 a year.
  • A new interface: calmer type, clear icons and a sidebar you can hide with ⌘ \ or Ctrl \.
  • Litigation vocabulary throughout: case theories, evidence, arguments, the theory test and pivotal evidence.
  • Whose theory is it: mark each theory as yours, the opposing side’s or an alternative.
  • Case templates for criminal defense, prosecution, civil and contract disputes.
  • Case memo export to an editable Word document.
  • Elenchus Pro: unlimited cases with a subscription; the free plan keeps every feature for one case.
